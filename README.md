# 🛍️ Análise de Desempenho das Lojas – Projeto Data Science

## 📌 Descrição
Este projeto tem como objetivo analisar o desempenho de quatro lojas com base em dados reais de vendas, avaliações, frete e localização geográfica. A análise foi realizada para ajudar o Senhor João a decidir qual loja vender, considerando fatores como faturamento, satisfação dos clientes e eficiência logística.

## 📊 Tecnologias utilizadas
- Python
- Pandas
- Matplotlib
- Google Colab

## 📁 Estrutura da análise
1. Faturamento total por loja
2.  Categorias de produtos mais e menos vendidos
3. Média de avaliação dos clientes
4. Custo médio de frete
5. Produtos mais e menos vendidos
6. Distribuição geográfica das vendas
7. Visualizações gráficas (barras, linhas, dispersão, mapas)

## 📈 Principais insights
- Loja 1 teve o maior faturamento, mas a pior média de avaliação e o frete mais caro.
- Loja 3 obteve a melhor média de avaliação dos clientes.
- A Loja 2 se manteve na média em todos aspectos.
- Loja 4 apresentou o menor faturamento e menor diversidade de produtos.
- A análise geográfica revelou padrões de concentração de vendas em determinadas regiões.

## ✅ Recomendação final
**Com base nas evidências, a recomendação é vender a Loja 4, por apresentar o menor desempenho geral e menor potencial de crescimento. As demais lojas demonstram maior rentabilidade e satisfação dos clientes.**
